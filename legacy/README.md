# Archived MATLAB implementation

This directory preserves the original publication-era cbFBA MATLAB scripts and helper functions.

The archived files are retained for provenance and historical comparison. They are not the maintained public API.

For new analyses, use the namespaced package under:

```text
src/+cbfba/
```

The historical scripts may rely on current-working-directory files, study-specific assumptions, COBRA Toolbox state, and output side effects.

See [../MIGRATION.md](../MIGRATION.md) for the modernization boundary.
